# VOCALEO: Mon Business Facile

Construis l’application SaaS VOCALEO décrite par l’utilisateur : assistant de gestion commerciale et financière mobile-first pour micro-entrepreneurs au Sénégal/Afrique francophone. Priorité MVP : authentification, onboarding court, dashboard, produits/stock, ajout vente, dépense, clients, historique, bilan mensuel, notifications, reçu, assistant IA simulé/préparé. Design premium fintech + IA, rassurant, ultra-simple, en français, devise FCFA. Utilise Lovable Cloud pour auth et données multi-tenant (organizations, products, customers, sales, sale_items, expenses, payments, inventory, inventory_movements, documents, notifications, monthly_reports), avec données démo Moussa Fashion. Prépare les interfaces/architecture pour WhatsApp, paiements locaux et documents sans intégrer de vraies transactions. Implémente les écrans, navigation mobile basse et desktop/tablette, états vides/loading/success/error/offline, toasts, confirmations, composants réutilisables. Respecte la philosophie : pas d’ERP ou de jargon comptable, chaque écran simple et orienté action.
